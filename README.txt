SALSA & BEER UNOFFICIAL FAN / DESIGN CONCEPT

Files: index.html, menu.html, about.html, styles.css, script.js, robots.txt, assets/

ANTI-INDEXING:
- Every HTML page has robots noindex/nofollow/noarchive/nosnippet/noimageindex.
- robots.txt disallows all crawlers and explicitly names several AI crawlers.
- IMPORTANT: robots.txt is voluntary and cannot guarantee that every crawler will comply. For a truly private test, use password protection / access controls or keep it local instead of publishing publicly.

If using GitHub Pages, remember that the repository and deployed files can still be publicly accessible by URL even with noindex. Do not treat GitHub Pages as private hosting.
